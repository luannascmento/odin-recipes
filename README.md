# Odin Recipes
This is a project designed to develop and practice HTML foundations lessons provided by [**The Odin Project**](https://www.theodinproject.com)'s Curriculum


## Objective
Cover the main topics about HTML basics, like as headings, paragraphs, images and links

## Conclusion
By the end of this project I'm now be able to:
- How to make a simple Webpage using HTML
- Understand the basic concepts of HTML elements and tags
- Manage heading, images, texts, links and lists tags
- Know the basic concepts of the Internet, Web and their work together
